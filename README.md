# Krypton Mod Right-Handed Cursor Themes (Dark & Light)

Праворукая (RH) модификация курсоров темы Krypton Mod для Linux. Все элементы и анимации переработаны с сохранением оригинальных задержек кадров и попиксельного качества.

Планируется обновление, добавление анимаций...

## Установка
```bash
mkdir -p ~/.icons
cp -r KryptonBlackRH KryptonWhiteRH ~/.icons/
```
